# Intended Users

The intended users of the code and data in this repo are the professor of CSE3000 to assess my work in that course and for myself to review certain computer ethics principles.  It is also a means to exersize git functions.

# Security Risks

The main security risk is someone gaining access to the repo in a manner that allows malicious data to be inserted, causing information on the repo to execute malware.  I do not have any identifying information on here, so that is the foremost apparent security risk.  A particularly petty actor could try accessing the repo to delete information, however, causing my assignments to be corrupted or missing.

# Steps to prevent
Information added to the repo can only be done via pull request, so changes made are contained to separate branches and thus any new information can be checked manually before modifying main.  Additionally, deletion of branches has been disabled, and reviews are enabled so I can analyze changes to the repo.  All this allows for a level of security in terms of data modification and loss.
